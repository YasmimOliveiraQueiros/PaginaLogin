# PaginaLogin · Sistema de Login e Cadastro

Interface de autenticação moderna, desenvolvida com foco em usabilidade,
estrutura limpa e aplicação real — pensada para o mercado de trabalho.

[🔗 Ver projeto ao vivo](https://pagina-login-umber.vercel.app)

---

## Sobre o projeto

Desenvolvi esse projeto pensando em como sistemas de login funcionam
em startups e empresas reais — não apenas como exercício visual, mas
como uma interface funcional e bem estruturada que poderia ser integrada
a qualquer aplicação.

O foco foi construir algo que parecesse de mercado: layout moderno,
código organizado e experiência de uso clara para quem interage com a página.

---

## Funcionalidades

- Tela de login com campos de e-mail e senha
- Alternância entre login e cadastro na mesma página
- Validação de campos via JavaScript
- Layout responsivo e estilizado
- Estrutura de código separada (HTML, CSS, JS)

---

## Tecnologias utilizadas

- HTML5 — estrutura semântica da página
- CSS3 — estilização moderna e responsividade
- JavaScript — lógica de validação e interação
